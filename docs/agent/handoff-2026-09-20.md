## Traps that have actually bitten on this arc

- **A container is UTC.** Do not reach for the host's zone.
- **The stored body is hashed to make `revision`** — fold a clock into it and
  every identical republish mints a new revision (defeats ij8.41). Substitute
  at serve time.
- **An HTML comment as a marker fails safe**; a text token shows a reader a raw
  placeholder when substitution does not happen.
- **Positional construction against a changing column list** breaks silently:
  `ArtifactRow(*row, …)` shifted a field when the SELECT changed, and the same
  shape put `owning_agent` into `acknowledged_by` in `decisions.py`. Both are
  keyword-based now; keep them that way.
- **errexit inside a function**: a function that re-enables `set -e` and returns
  non-zero kills the caller. Use `rc=0; run … || rc=$?`.
- **bash reads a script by byte offset while it runs.** Rewriting a running
  script kills it with a syntax error on a file that passes `bash -n`. That
  death reads as *Jeremy said nothing* when it happens to a waiter. Cured for
  the waiter; the diagnostic is general.
- **`readlink -f "${BASH_SOURCE[0]}"`** is load-bearing once a script is reached
  through a PATH symlink.
- **Seat grants belong to the seat, not the key**, and `?scope=all` must be
  **403, never silently narrowed**.
- **Prove a gate's arms with the literal input the real call passes.** A deploy
  waiter proved both arms with a full image tag, then reported a false TIMEOUT
  on a real deploy that passed a short hash.
