## The two things most likely to bite you

**1. There is no cleartext key on this machine any more.** All four seat keys
live in `ansible/secrets/artifacts-keys.sops.yaml` and reach a command on a
file descriptor:

```bash
ARTIFACTS_SEAT=baba_operator artifacts-key -- artifacts-publish page.html --title "…"
```

Seats: `baba_operator` (this seat's pages, including the status board),
`homelab_ops` (holds `decisions:read-all`), `warpgate_arc`, `cove_seat`. The old
files were renamed aside on 21 Sep at ~16:5x and the operator shreds them
**22 Sep 16:45**. `artifacts-publish` with no key source now tells you this in
its error. The descriptor is a **pipe**: read it once into a variable, because
the second read is empty and an empty bearer token is a 401 that reads exactly
like a revoked key.

**2. A deploy lands minutes after a push, unattended, and a "deploy: success"
can mean "stood down".** Batch your pushes; check the IMAGE on the Deployment
before telling anyone a thing is live:

```bash
KUBECONFIG=$HOME/.kube/config-homelab kubectl -n artifacts get deploy artifacts \
  -o jsonpath='{.spec.template.spec.containers[0].image}'
```

## Habits this arc keeps having to relearn

- **"Blocked" on a bead is a claim, not a fact.** Three beads on 20–21 Sep
  claimed blockers that had been false for a day; `ij8.19` depended on a half of
  `ij8.18` that had already shipped.
- **A check that has never fired has not been tested.** Sweep the live wall after
  shipping a new warning — the first version of the slot check fired on every
  template, because they ship their slots inside comments.
- **`cmd | tail; echo $?` reports tail's exit code.** It has misreported a
  failing ratchet as passing.
- **Bead prose is never a double-quoted shell argument** — backticks in it
  execute and eat words out of the note.
- **Render it and look at it.** Two faults on 21 Sep were invisible to 1,300
  passing tests and obvious in a screenshot.
